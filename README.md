## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Lootbound**. This trainer provides quality-of-life and gameplay assistance for Lootbound's single-player runs. It supports safer exploration, stronger equipment planning, more forgiving dice-based encounters, and improved control over combat resources without changing the game's core loot, aura, companion, and Guardian systems.

**Target Audience:** Players who want to experiment with item-aura layouts, companion equipment, route choices, Guardian combinations, and difficult runs with reduced punishment. It is also suitable for testing builds and learning the game's inventory and combat systems.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Lootbound uses a map-based expedition structure rather than continuous action movement. Choose routes between available locations, evaluate the risks and rewards of each node, and use the trainer after the map is fully displayed. Avoid activating inventory or combat options while transitioning between map nodes.

### Tools & Inventory

Each hero and companion has a separate equipment inventory. Items do not use fixed slots, can be rotated, and must fit within the available grid space. Arrange weapons, armor, and supporting items so that adjacent item auras create useful synergies. Activate inventory-related options only while managing equipment outside combat.

### World & Environment

Runs begin with the main hero alone and expand as companions are recruited along the route. Special rooms offer risk-based rewards, while each biome leads toward a Guardian whose parts are selected during the run. Use guaranteed rolls or preservation features before committing to high-value encounters.

### Combat & Weapons

Combat is turn-based. The player directly controls the main hero, while companions act automatically according to their abilities and equipment. Use health, armor, and resource options before selecting an ability or when preparing for elite enemies and Guardians. Disable experimental options before completing a fight if you want the run to retain its normal balance.
